# ระบบเช็กชื่อครูหน้าเสาธง — โรงเรียนอุดรพิชัยรักษ์พิทยา

เว็บแอปฟรี 0 บาท: หน้าเว็บอยู่บน **GitHub Pages** (โฟลเดอร์ `docs/`) ฐานข้อมูลและระบบล็อกอินอยู่บน **Supabase** ใช้ผ่านเบราว์เซอร์ใน LINE ได้ทั้ง iPhone/Android

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 45 นาที)

### 1. สร้างโปรเจกต์ Supabase
1. สมัคร supabase.com → New project (แพ็กเกจ Free) เลือก region Singapore
2. เมนู **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` → Run (รันซ้ำได้ ไม่เสียหาย)
3. เมนู **Project Settings → API** จดค่า `Project URL` และ `anon public key`

### 2. สร้างบัญชีผู้ดูแล (แอดมิน 1 คน)
1. **Authentication → Users → Add user** ใส่อีเมล+รหัสผ่านของแอดมิน (ติ๊ก Auto Confirm)
2. SQL Editor รัน (แก้อีเมลให้ตรง):
```sql
insert into admins (auth_user_id, email, display_name)
select id, email, 'ผู้ดูแลระบบ' from auth.users where email = 'admin@โรงเรียน.ac.th';
```

### 3. ตั้งค่าอีเมล (จำเป็น! ไม่งั้นลิงก์ลืมรหัสผ่านถึงครูไม่ได้)
SMTP เริ่มต้นของ Supabase ส่งได้เฉพาะสมาชิกทีมและ 2 ฉบับ/ชม. จึงต้องตั้ง SMTP ของตัวเอง (เช่น Gmail App Password, Brevo, Resend แพ็กเกจฟรี)
- **Authentication → Emails → SMTP Settings** เปิด Custom SMTP แล้วกรอกค่า
- **Authentication → Rate Limits** เพิ่มจำนวนอีเมล/ชม. ตามต้องการ
- **Authentication → URL Configuration**: Site URL = `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` และเพิ่ม Redirect URL `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/reset.html`
- แก้ข้อความเทมเพลต Reset Password เป็นภาษาไทยได้ที่ Emails → Templates

### 4. Deploy Edge Functions (auth, teacher, admin)
ติดตั้ง Supabase CLI แล้วรันในโฟลเดอร์โปรเจกต์:
```bash
supabase login
supabase link --project-ref <project-ref>
supabase secrets set ID_PEPPER="<สตริงสุ่มยาว ๆ เก็บไว้ ห้ามเปลี่ยนภายหลัง>" LINE_CHANNEL_ID="<Channel ID ของ LINE Login>" SITE_URL="https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>"
supabase functions deploy auth teacher admin
```
`config.toml` ปิด Verify JWT ให้แล้ว (แต่ละฟังก์ชันตรวจ token เอง) — ถ้า deploy ผ่านหน้าเว็บ ให้ปิด "Verify JWT" ทั้ง 3 ฟังก์ชัน
> ⚠️ `ID_PEPPER` ใช้เข้ารหัสเลขบัตรประชาชน ถ้าเปลี่ยนหรือหาย ครูทุกคนจะล็อกอินไม่ได้ ให้บันทึกไว้ที่ปลอดภัย

### 5. ตั้งค่า LINE (ให้เปิดในแอป LINE ได้)
1. developers.line.biz → สร้าง Provider → สร้าง Channel ชนิด **LINE Login** (ไม่ต้องมี Official Account)
2. แท็บ LIFF → Add: Size **Full**, Endpoint URL = `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`, Scope `openid` + `profile` จดค่า LIFF ID
3. เปลี่ยน Channel เป็น **Published**
4. ลิงก์ที่ให้ครู: `https://liff.line.me/<LIFF ID>` (ส่งเข้ากลุ่ม LINE ครูได้)

### 6. แก้ `docs/js/config.js`
ใส่ `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `LIFF_ID`, ชื่อโรงเรียน (anon key เปิดเผยได้ — ความปลอดภัยอยู่ที่ RLS + Edge Functions)

### 7. ขึ้น GitHub Pages
สร้าง repo → push โค้ดทั้งหมด → Settings → Pages → Source: branch `main` โฟลเดอร์ `/docs`

### 8. ตั้งค่าครั้งแรกในหน้าแอดมิน (`.../admin.html`)
1. **ตั้งค่า**: ปักหมุดจุดเสาธง, รัศมี (เริ่มต้น 100 ม.), เวลา 08:00 / มา ถึง 08:40 / ปิดรับ 12:00, วันทำการ, ชื่อโรงเรียน/ผอ./โลโก้ (ใช้ในหัวรายงาน), วันหยุด
2. **จัดการครู**: นำเข้า Excel (ดาวน์โหลดแม่แบบในหน้านั้น) หรือเพิ่มทีละคน → ระบบสร้างรหัสผ่านชั่วคราวให้ → **พิมพ์ใบแจกรหัส** (A4 ละ 8 ใบ) รหัสแสดงครั้งเดียว ไม่ถูกเก็บ
3. ครูเข้า → ใส่เลขบัตร+รหัสชั่วคราว → ยอมรับ PDPA → ตั้งรหัสผ่านเอง; ระบบผูกบัญชี LINE กับครูอัตโนมัติ (เข้าครั้งต่อไปไม่ต้องกรอกอีก)

### 9. (ไม่บังคับ) กัน Supabase Free หยุดพักเมื่อไม่มีการใช้งาน
เพิ่ม GitHub Secrets `SUPABASE_URL`, `SUPABASE_ANON_KEY` — workflow `.github/workflows/keepalive.yml` จะ ping ทุก 2 วัน

## กติกาการเช็กชื่อ (ตรวจที่เซิร์ฟเวอร์ ไม่เชื่อค่าจากเครื่องครู)
| เวลา (ไทย) | ผล |
|---|---|
| ก่อน 08:00 | ยังไม่เปิดรับ |
| 08:00–08:40 | **มา** |
| 08:41–12:00 | **สาย** |
| หลัง 12:00 | ปิดรับ (ให้แอดมินบันทึกให้) |

ต้องอยู่ในรัศมี, GPS คลาดเคลื่อน ≤ 100 ม., เป็นวันทำการ/ไม่ใช่วันหยุด, และ LINE ตรงกับบัญชีที่ผูก สถานะ ลากิจ/ลาป่วย/ราชการ/ลาคลอด/หมายเหตุ ครูแจ้งล่วงหน้าเองได้ แอดมินแก้ไขได้ทุกรายการ (ต้องระบุเหตุผล และถูกบันทึกใน Audit log) "ขาด" ไม่ได้เก็บเป็นสถานะ — รายงานแสดงเป็น "ไม่ได้เช็กชื่อ" สำหรับวันทำการที่ไม่มีบันทึก

## ข้อควรรู้
- **รูปแบบรายงานเป็นร่าง**: ส่งตัวอย่างแบบฟอร์มของโรงเรียน (รูป/PDF/Excel) มาเพื่อปรับให้ตรง; ไฟล์ที่เกี่ยวข้อง `docs/js/admin-reports.js` และกฎ print ใน `docs/css/style.css`
- ข้อความ PDPA เป็นแม่แบบ ควรให้ผู้รับผิดชอบของโรงเรียนตรวจก่อนใช้จริง (`docs/js/teacher.js`)
- การสำรอง: หน้า "สำรองข้อมูล" ดาวน์โหลด Excel (อ่านได้) และ JSON (เก็บค่าแฮชเลขบัตร แต่ไม่รวม `ID_PEPPER`) — v1 ยังไม่มีเครื่องมือกู้คืน; Supabase Free ไม่มีสำรองอัตโนมัติ แนะนำสำรองสัปดาห์ละครั้ง
- Supabase จำกัดการยืนยันตัวตนต่อ IP; ระบบเลี่ยงด้วยการให้เบราว์เซอร์ครูแลก token เอง ไม่ผ่านเซิร์ฟเวอร์ จึงรองรับครูหลายคนใช้ Wi-Fi โรงเรียนเดียวกัน
- GPS ปลอมได้ด้วยแอปพิเศษ (ลดความเสี่ยงด้วยการบังคับ LINE ที่ผูกไว้ + ความแม่นยำ) ถ้าต้องการเข้มขึ้นให้เพิ่ม QR รายวันที่เสาธง (เฟส 2)
- เฟส 2 ที่แนะนำ: QR รายวัน, เครื่องมือกู้คืนข้อมูล, แจ้งเตือนครูที่ยังไม่เช็กชื่อ, สรุปส่งอีเมลรายเดือน

## ทดสอบ
ตรรกะเซิร์ฟเวอร์ทดสอบกับโค้ดจริง 58 กรณี (ล็อกอิน/ล็อกบัญชี/LINE/เวลา/GPS/แจ้งสถานะ/แอดมิน/สำรอง) และหน้าเว็บแอดมิน+ครูเปิดได้โดยไม่มี error ใน Chrome จำลอง; ยังไม่ได้ทดสอบกับ Supabase/LINE จริง — หลังติดตั้งควรลองกับครู 2–3 คนก่อนใช้ทั้งโรงเรียน
